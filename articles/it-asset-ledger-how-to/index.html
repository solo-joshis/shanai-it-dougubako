IT資産管理台帳の作り方：兼任担当者が最初にそろえる3つの表

2026/09/24

総務や経理と兼任で、会社のPCやソフトウェアの管理を任された人に向けた記事です。

結論：台帳は「機器」「ライセンス」「割当」の3つに分ける

IT資産管理台帳の目的は、次の3つの質問にすぐ答えられるようにすることです。

  • どのPCを、誰が使っているか
  • 保証がいつ切れるか
  • ソフトウェアのライセンスが足りているか

このために、記録するデータを次の3つの表に分けます。

表1行に書くもの例
ハードウェア台帳機器1台PC-0001（ノートPC）、SP-0001（スマホ）
ライセンス台帳契約1件SW-0001（オフィスソフト、10ライセンス）
ライセンス割当「誰にどのライセンスを割り当てたか」1件SW-0001 を利用者01に割り当て

この3つがあれば、台数の集計や期限の一覧は、あとから数式で作れます。

なぜ3つに分けるのか

1枚の表にまとめると、次のような問題が起きやすくなります。

  • ライセンスの数が合わなくなる：1つの契約を何人もが使うため、PCの行に「使っているソフト」を書くと、同じ契約の情報が何行にも散らばります。契約の本数を変えたとき、直す場所が増えます。
  • 割当の履歴が残らない：異動や退職でライセンスを外すとき、行を消すと「いつまで誰が使っていたか」が分からなくなります。割当を別の表にして「解除日」を書けば、履歴を残したまま、今の割当数だけを数えられます。
  • PCを使わないライセンスを書く場所がない：スマホ用のアプリや、人に割り当てるクラウドサービスの契約は、PCの行には書けません。

最低限そろえる項目

最初から全部の列を埋める必要はありません。まずは「必須」の列だけ埋めて、残りは分かったときに書き足します。

手順

1. 管理番号のルールを決める

管理番号は、台帳と実物を結びつけるための番号です。次のように決めておくと迷いません。

  • 種別ごとに記号を分ける（例：PC＝ノートPC・デスクトップPC、SP＝スマホ、TB＝タブレット）
  • 番号は4桁にそろえる（PC-0001）。並べ替えたときに順番が崩れません
  • 廃棄した機器の番号は、ほかの機器に使い回さない。過去の記録と混ざらないようにするためです
  • 番号を書いたラベルを機器に貼る

2. 機器を登録する

最初の登録が、いちばん手間のかかる作業です。一度に全部そろえようとせず、次の順で進めます。

  1. 手元にある購入の記録（納品書・請求書・購入履歴）から、機器の一覧を作る
  2. 管理番号・種別・ステータスの3つだけを埋めて、全台を1行ずつ登録する
  3. 機器を見て回るときに、ラベルを貼りながら使用者・設置場所・シリアル番号を書き足す
  4. 保証期限は、メーカーの保証確認ページや購入時の書類で確かめて入力する

3. 保証期限を「状態」の列で知らせる

保証期限の列を毎回目で追うのは大変です。隣に「保証の状態」の列を作り、数式で文字を出します。色だけでなく文字でも出しておくと、印刷したときや、色の区別がつきにくい人にも伝わります。

例として、ハードウェア台帳の列を次のように置いた場合の数式です（列の位置は自分の台帳に合わせて読み替えてください）。

  • C列：保証期限、D列：保証の状態、F列：ステータス

D2に入れる数式：

=IF(C2="","",IF(F2="廃棄済","",IF(NOT(ISNUMBER(C2)),"日付エラー",IF(C2<TODAY(),"期限切れ",IF(C2-TODAY()<=90,"期限間近","")))))

この数式は、次のように判定します。

  • 保証期限が空欄、またはステータスが「廃棄済」なら何も出さない（廃棄した機器まで警告しないため）
  • 日付として読めない値なら「日付エラー」
  • 今日より前なら「期限切れ」、今日から90日以内なら「期限間近」

あわせて条件付き書式で、「期限切れ」の行を赤、「期限間近」の行を黄色にしておくと、開いたときにすぐ目に入ります。

4. ライセンスの残数を自動で出す

ライセンス台帳の「割当数」は、ライセンス割当の表から数えます。このとき、次の2種類の行は数えないようにします。

  • 割当日が未来の行（まだ使い始めていない）
  • 解除日が今日以前の行（もう外した）

例として、ライセンス台帳のA列にライセンスID、ライセンス割当の表のA列にライセンスID・C列に割当日・D列に解除日を置いた場合、ライセンス台帳の割当数の列（2行目）に入れる数式です。

=COUNTIFS('ライセンス割当'!$A$2:$A$1000,A2,'ライセンス割当'!$C$2:$C$1000,"<>",'ライセンス割当'!$C$2:$C$1000,"<="&TODAY(),'ライセンス割当'!$D$2:$D$1000,"")+COUNTIFS('ライセンス割当'!$A$2:$A$1000,A2,'ライセンス割当'!$C$2:$C$1000,"<>",'ライセンス割当'!$C$2:$C$1000,"<="&TODAY(),'ライセンス割当'!$D$2:$D$1000,">"&TODAY())

どちらも「割当日が空欄でなく、今日以前」の行だけを対象にし、前半は「解除日が空欄の割当」、後半は「解除日が明日以降の割当」を数えています。残数は「保有数 − 割当数」で出し、マイナスになったら赤にします。

注意：COUNTIFS は、検索する値に「*」や「?」が含まれるとワイルドカードとして扱います。ライセンスIDには英数字とハイフンだけを使ってください。

5. 割当の表を点検する

ライセンス割当の表は、入力ミスがあっても残数の数字だけでは気づきにくい表です。月に1回など時期を決めて、次の点を確かめます。

  • 割当日が空欄の行がないか
  • 日付の欄に文字（「来月」など）が入っていないか
  • 解除日が割当日より前になっていないか
  • 同じ人に、同じライセンスが2回割り当てられていないか
  • 退職・異動した人の割当に、解除日が入っているか

よくある失敗

  • 1枚の表に全部書く：上で書いたとおり、ライセンスの数や割当の履歴が追えなくなります。
  • 備考にパスワードを書く：台帳は共有されることが多いファイルです。パスワードや個人の連絡先は書かず、パスワードの管理は別の方法にします。
  • 自動計算の列に手で数字を入れる：数式が消え、その行だけ集計から外れます。自動計算の列は見出しの色を変えるなどして、入力する列と区別します。
  • 見出しの名前を途中で変える：集計の数式や、ほかの人が作った仕組みが見出しの名前を頼りにしている場合、動かなくなります。
  • 最初に完璧を目指す：全部の列を埋めてから使おうとすると、登録が終わりません。必須の列だけで使い始め、少しずつ埋めます。

まとめ

  • 台帳は「機器」「ライセンス」「割当」の3つの表に分ける
  • 最初は必須の列だけを埋めて使い始める
  • 保証期限とライセンスの残数は数式で自動にし、色だけでなく文字でも知らせる
  • 割当の表は、時期を決めて点検する
